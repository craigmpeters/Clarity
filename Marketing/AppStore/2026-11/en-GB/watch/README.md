Two branded images in `upload/`, with the supplied Clarity logo. Both are 416 × 496 RGB PNGs with no alpha, matching the Series 10/11/12 size accepted by Apple. Use the same Watch size across localizations.

- Tasks at hand: the actual Watch task list with a demo task.
- Small daily steps: the actual Watch reading habit page.

`plain/` offers full-size app-only alternatives; choose either the branded set or the plain set. `raw/` contains the simulator captures. `editable/` contains self-contained SVG layouts. The capture times are the actual simulator times; Watch status-bar override is unsupported.

Captured on Apple Watch Series 11 (46mm), watchOS 27.0. Demo cache data was seeded in the disposable simulator. No app source changed. No assets uploaded. Regenerate using `../render-devices.cjs` with the dependencies used by the earlier screenshot set.
